# 壁纸切换器 v0.4.4 发版简介

> Release 页简介用，可直接复制。详细技术记录见 CHANGELOG.md。

## 一句话

动态桌面壁纸工具：每屏独立轮播 + 深度视差 + 双层人物合成，本版新增「深度呼吸律动」，冷开机更快更稳。

## 本版亮点

### ✨ 深度呼吸律动（新）

- 开启后，画面里的**近景会像呼吸一样缓慢起伏**（人物轻微微动、背景稳住），静态壁纸多一层"活"感。
- 设置 › 外观 › 深度视差 › **「深度呼吸律动」**，**默认关闭**；打开后可用滑条微调幅度（±0.5%~±5%，默认 ±1.5%）。
- 需要深度图（有深度缓存的壁纸自动生效），会略增 GPU 占用。

### ⚡ 冷开机更快

- 启动时直接读取已有的深度缓存，不再等深度引擎探测完成——重开机后壁纸带视差更快出现。
- 舞台窗口预创建（与扫描并行），开机后窗口被误判全屏导致的**首帧冻结已修复**。
- 实测壁纸首帧从 ~15s 缩短到 ~12s（本机 4 万张图库 + 机械盘环境）。

### 🛡 分割模型按需下载（新）

- 「双层视差」所需的动漫分割模型（isnetis，176MB）不再内置，首次开启时弹窗一键下载（断点续传 + SHA256 校验，可取消），之后不再提示。

### 🧹 精简

- 移除时段滤镜（与氛围调色板重复，按时段上色统一走「氛围调色板」）。
- 移除 idle 微动画（双层合成下感知不到）。

## 升级说明

- 直接安装覆盖，配置与缓存（深度图/缩略图）全部保留。
- 旧配置里已退役的选项会被自动忽略，无需手动清理。

## 已知事项

- 双层视差对低配机器有可感知的首次生成开销（每张带人物图首次显示多花 1~2s 补背景板），开启前会弹性能提示。
- 深度呼吸律动与双层视差同开时观感最佳；两者都吃 GPU，笔记本可按屏选择性开启。
