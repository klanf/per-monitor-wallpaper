# 《壁纸切换器》介绍视频 · 口播稿

写的是对着镜头说话的感觉，不是念稿子。口播按一口气一行断开，方便直接对着提词器读；
字幕另给，只留关键词，不要跟着口播逐字念。

- 主版本 **5 分 30 秒**（实测 329.9s），11 镜 + 片头 = 12 段，口播 54 句。
- **时长已回填**：镜 3B / 4 / 6 / 7 / 8 的配音都按 TTS 实测长度重排过了
  （28.2 / 11.3 / 21.0 / 10.6 / 62.4 秒）。估算跟实测的差距主要在语速 ——
  按字数折算普遍偏快 10–20%，以后估算直接按 3.2 字/秒算。
- **镜 4 / 6 / 7 是「说一句就走」的短镜**（2026-09-13 第二轮定的调子）：
  随机不重复、右键整理、Ctrl+I 都不是这个工具的主卖点，展开讲会把节奏拖垮，
  所以各压到 10 / 14 / 8 秒，只留结论。**但「删图」必须留** ——
  它能进回收站、删完立刻补位，这是真正解决痛点的一条，不能省。
- **镜 8 改成热键专题**：明确讲「热键可以自己录」，并且要把

  它跟镜 3B 不重复：3B 讲的是「先选屏」这个概念（用界面上的预览徽标），
  镜 8 讲的是「同一个能力用热键也能用，而且窗口关掉照样生效」。
- 镜 0 是后加的片头：讲「为什么做这个」。原本这段内容散在镜 1 开头，
  加片头之后镜 1 的前两句要删掉，不然同一件事会说两遍。
- **镜 3B 是第二轮补的一镜**（2026-09-13）：讲「切换显示 → 分别切图」。

### 镜 8 ｜ 03:41.8 – 04:44.1（实测 62.4s）｜ 热键自己录，切屏换图不用开窗口

**这一镜是本片的第二个重点**（第一个是镜 3）。上一版只说了「有 7 个热键」，
**没说清它们默认是一条都没设的、要用户自己录**，也没演示「切到下一台显示器」这条。
两件事都得补齐。

**取景**　**双屏**——后半段要看两块屏各自的反应，单屏拍不到。
演示热键时窗口**先别关**（缩到约 1100×820、靠左），这样界面反馈和桌面变化同时看得见；
最后关掉窗口再按一次，证明后台确实生效。

**实测前提（照抄代码，别想当然）**

- `config.hotkeys` 七个字段默认值**全是空串**：`cycleMonitor / next / prev /
  playPause / delete / toggleWindow / info`。**不录就一个热键都没有**。
- 界面上的中文名：切到下一台显示器 / 下一张 / 上一张 / 暂停·继续 /
  删除当前这张到回收站 / 显示·隐藏主窗口 / 查看当前这张的图片信息。
- 组合键**必须带 Ctrl / Alt / Shift / Win 里的一个**，不带会被拒绝注册
  （`validateAccelerator`）。这条顺口带一句就行，不用展开。
- 热键跟界面按钮一样，**作用于「当前预览目标」那块屏**；`cycleMonitor` 干的就是切这个目标。

**动作**

| 步骤 | 操作 | 画面上要发生的事 |
|---|---|---|
| 1 | 设置 → 滚到「全局热键」 | 7 行列表，右边全是「未设置」 |
| 2 | 点「下一张」那行 → 按 `Ctrl+Alt+Right` | 那行变成 `Ctrl+Alt+Right` |
| 3 | 点「切到下一台显示器」那行 → 按 `Ctrl+Alt+M` | 那行变成 `Ctrl+Alt+M`（**这条要特写**） |
| 4 | 按 `Ctrl+Alt+M` | toast：预览已切换到「显示器 2」 |
| 5 | 按 `Ctrl+Alt+Right` | **副屏桌面换**，**主屏那张不动** |
| 6 | 按 `Ctrl+Alt+M` → 再按 `Ctrl+Alt+Right` | **主屏换**，副屏保持 |
| 7 | 关掉窗口 → 再按一次 `Ctrl+Alt+M` + `Ctrl+Alt+Right` | 桌面照样换；托盘图标还在 |
| 8 | 鼠标移到托盘上悬停 | 气泡显示当前文件名 |

**讲解卡**　新增 `08b`（七个热键名排成两列，「切到下一台显示器」高亮），插在**本镜开头 5.0s**，
风格跟 03a / 03b 一致。**原来的 `08a`（「关窗口 ≠ 退出」四条）作废** ——
那四条现在口播里一句话带过，不值得立一张卡，两张卡连续出会把本镜切碎。

**字幕**　7 条热键，默认都是空的 / 自己录，带 Ctrl·Alt·Shift·Win / 切屏热键：换哪块屏你说了算

**口播**

> 关窗口不等于退出，它会缩到托盘，接着轮。
> 鼠标放托盘上能看到现在放的是哪张。
> 平时我基本不点它，全局热键更方便。
> 热键在设置里，一共七条，每一条都能自己录：点一下，按下你想用的组合键就行。
> 这七条默认是空的，得自己设；组合键要带 Ctrl、Alt、Shift 或者 Win 里的一个，不带它不收。
> 七条里有下一张、上一张、暂停，还有一条叫「切到下一台显示器」。
> 我按一下切屏，切到副屏，再按下一张 —— 换的是副屏这张，主屏没动。
> 再按一下切回主屏，按下一张 —— 这回换的是主屏，副屏还是刚才那张。
> 窗口关掉以后也一样生效，所以你可以完全不管它，它在后面自己换。
> 换图除了按键，触控板双指横滑、触摸屏手指左右划也能用。

（原稿还有一句「顶栏和底下这条会自己淡出」——**删了**。它是纯 UI 细节，
跟本镜「热键」的主题无关，而且得单独录一段「等淡出 → 再滑回来」才演得出来，
多花 7 秒换一句无关信息，不划算。）

**跟镜 3B 的分工**（别讲成两遍）：3B 用界面上的「预览」徽标，讲的是
「换图之前得先选屏」这个**概念**；这一镜用热键，讲的是「同一个能力不用开窗口也能用」，

## 五、二期素材：踩过的坑

这轮视频里只在镜 8 提了一句触摸屏。如果要做一期「开发踩坑」，下面这些都能直接讲：

| 坑 | 怎么讲 |
|---|---|
| 触摸屏划不动 | CSS 里 `touch-action` 一行没写，浏览器把左右拖当成页面滚动接管了，接管那刻发 `pointercancel`，手势代码就把这次滑动丢掉。而且这行只能写在画布自己身上，写到外层容器上，设置面板跟着一起滚不动 |
| 热键录了没反应 | 全局热键必须带 Ctrl/Alt/Shift/Win 里的一个，不带的话会占掉全系统输入，程序直接拒绝注册。另外键名得写字面字符，`Period` 这种名字会抛异常 |
| 图标换了看着没变 | Windows 是按路径缓存图标的。重打包后 exe 里的图标其实已经换了，是缓存没刷新 |
| 工具栏藏起来叫不回来 | 唤醒绑的是 `pointerdown`。原来绑的 `mousedown`，触摸屏不产生鼠标事件，手指点上去一点反应都没有 |
| 3 万张图怎么扫得快 | 排序器只构造一次就够了。要是每张图都新建一次 `Intl.Collator`，十万张规模下会吃掉扫描流程一半以上的时间 |

## 六、开录之前

**素材**

- 界面截图：`docs/界面-*.png` 六张，够用
- 对照表：README 里「与同类工具的差异」那一节
- 录屏用 2560×1440 以上，OBS 窗口捕获，口播单独走一个音轨，后期好改

**容易翻车的几件事**

1. **别用 `dist/` 里的安装包录。** 那两个 0.1.0 的 exe 是 9 月 12 日 13:35 打的，
   不含后来那个「切了播放顺序胶片条不跟着重排」的修复。镜 4 要展示这个效果，
   得用 `npm start` 起的版本。
2. **图库换成演示目录。** 之前 README 截图就因为这个重拍过一次，
   真实路径和私人图片会跟画面一起录进去。`npm run fixtures` 能生成一批测试图。
3. **演示图不用没授权的画师作品。** 公开视频里放大段素材，法律上是「复制 + 信息网络传播」，
   不在合理使用范围内，署名与否都构成侵权。演示图一律用自己生成或 CC0 的素材。
   （`D:\demo壁纸` 原来那批 Pixiv 插画已停用，不进任何公开产出。）
4. **每一镜开录前，先确认顶栏「预览」指向的是录到的那块屏。** 这条是第二轮才立的规矩。
   「下一张」「上一张」、全局热键、删除，全都作用于**当前预览目标**那一块屏；
   目标是副屏、而副屏又没进画面，观众就只看见点了按钮、什么都没变（第一轮就是这么翻的车）。
   唯一例外是镜 3B 和镜 8 —— 这两镜演的就是切这个目标。
   镜 8 还要多确认一次：**开录前热键得先录好**，默认七条全是空的，
   现场录会把「点一下、按下组合键」这个过程也拍进去（其实更真实，但要多留 8 秒）。
   顺带记住：**改设置不会重画桌面壁纸**（`config:set` 只走 `rebuild('config')`，不写桌面），
   想让桌面当场变，只有「切到某块屏 + 点下一张 / 按热键」这一条路。

**几个小细节**

- 录之前把自动隐藏调长一点，比如 6 到 8 秒。不然讲着讲着顶栏淡出了，手忙脚乱
- 托盘里别的图标先收起来
- 演示删除时找个专门的「垃圾桶」文件夹接着，别真把手上的素材删了
- 演示手势那一下拖慢点，横向给够 60 像素。拖太短切不动，观众会当成 bug
- 镜 8 要录两条热键，组合键挑冷门的：`下一张` 用 `Ctrl+Alt+→`、
  `切到下一台显示器` 用 `Ctrl+Alt+M`，免得录到一半触发别的软件。
  两条都带 Ctrl+Alt，也顺便把「必须带修饰键」这条演出来了
